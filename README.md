# 🔐 Sistema de Login em Python

Projeto simples de autenticação de usuário desenvolvido em Python, criado com o objetivo de praticar conceitos fundamentais de lógica de programação.

## 📌 Sobre o projeto

O sistema solicita ao usuário um nome de usuário e uma senha e compara as informações inseridas com as credenciais cadastradas no programa.

Caso as credenciais estejam corretas, o acesso é autorizado. Caso contrário, o sistema informa que o usuário ou a senha estão incorretos.

## ⚙️ Funcionalidades

- Entrada de usuário e senha pelo terminal
- Armazenamento de credenciais utilizando dicionários
- Comparação das credenciais informadas
- Validação de acesso
- Mensagem de sucesso ou erro no login

## 🛠️ Tecnologias utilizadas

- Python

## 🧠 Conceitos praticados

Neste projeto foram utilizados conceitos básicos de Python, como:

- Variáveis
- `input()`
- Dicionários
- Estruturas condicionais `if` e `else`
- Comparação de dados

## ▶️ Como executar

1. Tenha o Python instalado no computador.
2. Clone ou baixe este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute:

`python login.py`

5. Informe o usuário e a senha solicitados pelo programa.
